## 🎬 CS WORKFLOWS

### WORKFLOW 1: ONBOARDING → ACTIVATION (Days 0-7)

**Goal:** Get customers using the product in their first week.

**Checklist:**
```
Day 0: ✅ Account created
       ✅ Welcome email sent
       ✅ Dashboard access granted

Day 1: ✅ First report delivered
       ✅ Email notification sent
       ✅ Dashboard email sent

Day 2: ✅ Education email sent
       ✅ Video watched (target: 70%+)
       ✅ First login tracked

Day 3: ✅ Follow-up email sent
       ✅ Onboarding checklist progress tracked
       ✅ Support ticket response < 4 hours if needed

Day 7: ✅ Activation complete (downloaded report, logged in 3+ times)
       ✅ "You're all set" email sent
       ✅ Success badge unlocked
```

**Activation Definition:**
```
✅ Email verified
✅ Downloaded 3+ reports
✅ Logged in 5+ times
✅ Viewed 5+ pages in dashboard
✅ Added 1+ stock to watchlist

→ If NOT activated by Day 7: Trigger re-engagement campaign
```

---

### WORKFLOW 2: ENGAGEMENT TRACKING (Days 8-30)

**Goal:** Identify at-risk customers early, maximize feature adoption.

**Weekly Check-in:**
```
Every Tuesday at 09:00 UTC+2:

For each customer segment:
1. BASIC users
   ├─ Check: Opened last 3 reports?
   ├─ Check: Logged in this week?
   ├─ Check: Used any filters?
   └─ Action: If NO to all → Send engagement email

2. PRO users
   ├─ Check: Used custom filters?
   ├─ Check: Accessed API?
   ├─ Check: Used backtesting?
   └─ Action: If NO → Send "PRO features" email

3. ENTERPRISE users
   ├─ Check: Monthly usage metrics
   ├─ Check: Support ticket response satisfaction
   ├─ Check: Executive sponsor engagement
   └─ Action: Schedule quarterly business review
```

**Engagement Score (0-100):**
```
+10 points: User logged in
+15 points: Downloaded report
+10 points: Used filters
+20 points: Used PRO feature (custom filter, API, backtesting)
+5 points: Viewed knowledge base
+10 points: Attended webinar/training

Scoring:
70+: ✅ Healthy — No action
50-69: ⚠️ At-risk — Send engagement email
<50: 🚨 Critical — Contact user directly
```

### WORKFLOW 3: CHURN PREDICTION & PREVENTION (Days 31+)

**Early Warning Signs:**
```
🚨 CRITICAL CHURN SIGNALS:
├─ No login in last 14 days
├─ No report download in 21 days
├─ Support ticket with negative sentiment (bug/issue)
├─ User asking about refund/cancellation
├─ BASIC user hasn't opened dashboard in 30 days
└─ PRO user hasn't used any PRO feature in 45 days

⚠️ MEDIUM CHURN SIGNALS:
├─ Engagement score dropped >20 points
├─ Lower login frequency (used to daily, now weekly)
├─ Zero interaction with support/community
└─ Feature request without action (frustrated user)
```

**Churn Prevention Campaigns:**

**Campaign 1: "We Miss You" (14 days no login)**
```
Email subject: "🎯 The Best Robot Trader Report This Month"

Content:
- Highlight: Top opportunity from this month's screening
- Stats: "We found 150+ opportunities for you"
- Social proof: "Here's what other users did with reports like this"
- Call-to-action: "View all reports in 30 seconds"

Follow-up (if no response): Calendar invite for "15-min strategy call"
```

**Campaign 2: "Unlock PRO" (BASIC user, Day 45)**
```
Email subject: "✨ See What PRO Users Are Getting (And Why They Love It)"

Content:
- Case study: BASIC user upgraded to PRO, found 3 stocks
- Feature showcase: Custom filters, API, backtesting
- Offer: "First month 50% off (ends in 3 days)"
- FAQ: "Why upgrade?"

Result: 20%+ of BASIC users typically upgrade
```

**Campaign 3: "Let Me Help" (Negative support ticket)**
```
Trigger: Customer reports a bug or expresses frustration

Action:
- Founder (Luciano) personally responds within 1 hour
- Offer: "Let me schedule a call to fix this together"
- Resolution: 90%+ satisfaction rate when founder engages
```

**Campaign 4: "Don't Go" (Refund request)**
```
Trigger: Customer initiates refund request

Response (within 1 hour):
- Acknowledge their concern
- Ask: "What would make you stay?"
- Offer: Options to fix issue (refund, free month, upgrade to PRO)
- Escalate to founder if needed

Retention rate: 40%+ with proactive outreach
```
