### 1.3 — FILTER NODE (Check Today's Post)

**Node Type:** Set / Filter

**Logica:**
```javascript
// Controlla se oggi c'è un post programmato
const today = new Date().toISOString().split('T')[0]; // "2026-05-04"

return $input.all().map(post => {
  const postDate = post.json.Data; // "2026-05-04"
  return postDate === today;
}).some(x => x);

// Se TRUE: continua
// Se FALSE: stop workflow (no post today)
```

**Output:** Boolean (continue o skip)

### 1.4 — CLAUDE API NODE (Post Generation)

**Node Type:** HTTP Request

**Method:** POST
**URL:** `https://api.anthropic.com/v1/messages`

**Headers:**
```json
{
  "x-api-key": "{{ $env.ANTHROPIC_API_KEY }}",
  "anthropic-version": "2023-06-01",
  "content-type": "application/json"
}
```

**Body:**
```json
{
  "model": "claude-opus-4-20250514",
  "max_tokens": 500,
  "messages": [
    {
      "role": "user",
      "content": "Tu sei un content creator per Fuerte Venture Capital.

Crea un post LinkedIn in italiano su: {{ $node['Google Sheets'].json.Tema }}

Requisiti:
- Tono: Professionale ma accessible
- Lunghezza: 250 max caratteri
- Hook: Prima 30 caratteri devono attrarre
- Hashtag: 3-5
- Emojis: Max 2

Rispondi SOLO con il post, senza prefissi."
    }
  ]
}
```

**Response Processing:**
```javascript
// Estrai il testo dal response Claude
const response = $node['Claude API'].json;
return {
  post_text: response.content[0].text,
  generated_at: new Date().toISOString()
};
```

## 🔐 WORKFLOW 2: WEBHOOK APPROVAL + PUBLISH

### 2.1 — WEBHOOK TRIGGER NODE

**Node Type:** Webhook

**Method:** POST
**URL:** `https://your-n8n.cloud/webhook/linkedin_post_approval`

**Expected Payload:**
```json
{
  "post_id": "2026-05-04",
  "action": "approve",
  "edited_text": "(optional) testo modificato",
  "timestamp": "2026-05-04T10:00:00Z"
}
```

---

### 2.2 — CONDITIONAL LOGIC

**Node Type:** Switch

**Condition:**
```
IF action == "approve" → branch PUBLISH
IF action == "edit" → branch SAVE_DRAFT
IF action == "reject" → branch LOG_REJECTION
```

---

### 2.3 — LINKEDIN API PUBLISH

**Node Type:** HTTP Request (POST)

**Setup (per BRANCH PUBLISH):**

```
URL: https://api.linkedin.com/rest/posts
Method: POST
Auth: Bearer {{ $env.LINKEDIN_ACCESS_TOKEN }}

Body:
{
  "author": "urn:li:person:{{ $env.LINKEDIN_PERSON_ID }}",
  "commentary": "{{ $node['Webhook'].json.edited_text OR $node['Claude API'].json.content[0].text }}",
  "visibility": "PUBLIC",
  "distribution": {
    "feedDistribution": "MAIN_FEED",
    "targetEntities": [],
    "thirdPartyDistributionChannels": []
  },
  "content": {
    "media": {
      "id": "{{ $node['LinkedIn Image Upload'].json.media_id }}"
    }
  }
}
```

**Success Response:**
```json
{
  "id": "linkedin_post_id_xxxxx",
  "published_at": "2026-05-04T10:15:00Z",
  "status": "PUBLISHED"
}
```
