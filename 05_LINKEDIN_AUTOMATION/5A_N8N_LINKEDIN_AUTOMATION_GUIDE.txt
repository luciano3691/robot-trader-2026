```

  → Use pre-written post template
  → Notify luciano via email

  → Use stock image (Unsplash integration)
  → Notify luciano
  
IF LinkedIn API fails:
  → Save to Google Drive as draft
  → Manual re-publish later
  → Log error + retry
  
IF approval webhook times out:
  → Auto-delete draft after 24h
  → Send reminder email
```
