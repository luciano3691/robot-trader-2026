## DATABASE SCHEMA

Main fields in DATABASE_RECIPIENTS.json:

ADMIN RECIPIENTS:
- id: unique identifier
- email: email address
- status: active/inactive
- frequency: daily/weekly/manual
- markets: [AZIONI, FONDI, ETF]
- created_date: YYYY-MM-DD
- notes: description

CUSTOMER RECIPIENTS:
- Same as above, plus customer_id and customer_name

METADATA:
- last_report_run: timestamp of last screening
- total_emails_sent: count of emails sent

---

## HOW IT WORKS

Step 1: DATABASE IS LOADED (08:05 UTC+2)
- Load DATABASE_RECIPIENTS.json
- Parse JSON

Step 2: ACTIVE RECIPIENTS ARE FILTERED
- Get all active recipients where:
  * status = 'active'
  * frequency = 'daily'
  * 'AZIONI' in markets

Step 3: REPORT IS SENT
- For each filtered recipient:
  * Send report to email
  * Log transmission

Step 4: DATABASE IS LOGGED
- Update metadata (last_report_run, total_emails_sent)
- Save back to file

## MANAGEMENT OPTIONS

Option 1: Manual Edit (Simple)
- Open DATABASE_RECIPIENTS.json with text editor
- Modify entries directly
- Save and restart scheduler
- Pros: Simple, no dependencies
- Cons: Manual, error-prone

Option 2: CLI Tool (Recommended)
- python3 manage_recipients_CLI.py list
- python3 manage_recipients_CLI.py add-admin --email xxx --name xxx
- python3 manage_recipients_CLI.py remove --id admin_001
- python3 manage_recipients_CLI.py update --id admin_001 --status inactive
- Pros: Easy, validated, logged
- Cons: Command line only

Option 3: Admin Dashboard (Future)
- Open ADMIN_DASHBOARD_EMAIL_RECIPIENTS.html in browser
- Provides visual form for add/remove/edit
- Pros: User-friendly, visual
- Cons: Needs backend integration

## TROUBLESHOOTING

Problem: DATABASE_RECIPIENTS.json not found
Solution: Copy file to working directory

Problem: Email not sent (but no error)
Debug:
1. Check recipient status
2. Verify email is active and frequency is daily
3. Check email spelling
4. Test with update command

Problem: Too many emails sent (sent to everyone)
Debug:
1. Check filter logic
2. Verify market filter includes AZIONI
3. Deactivate recipient if needed
