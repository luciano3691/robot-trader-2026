
# MAILCHIMP EMAIL AUTOMATION SETUP GUIDE

## 📋 OVERVIEW

Sistema di email automation per Fuerte Venture Capital usando Mailchimp.
- Waitlist capture (landing page forms)
- Automated email sequence (5 email pre-written)
- Segmentazione per piano (BASIC/PRO/ENTERPRISE)
- Analytics + tracking

---

## 🔧 MAILCHIMP SETUP STEP-BY-STEP

### STEP 1: CREATE ACCOUNT & AUDIENCE

1. Vai su mailchimp.com → Sign up
2. Email: info@fuerteventurecapital.com
3. Create new Audience: "Robot Trader 2026"
4. Audience settings:
   ```
   ├─ Name: Robot Trader 2026
   ├─ Default sender: Fuerte Venture Capital <info@fuerteventurecapital.com>
   ├─ Default "From name": Luciano Manicardi, Fuerte VC
   ├─ Reply-to: luciano.manicardi@lineexpress.it
   └─ Default language: Italian + Spanish
   ```

---

### STEP 2: CREATE MERGE FIELDS (Personalization)

In Audience Settings → Manage Audience → Additional fields:

```
MERGE FIELDS:
├─ FNAME (First Name) — Required
├─ LNAME (Last Name) — Optional
├─ PLAN (Piano Interesse) — Dropdown: BASIC/PRO/ENTERPRISE
├─ COUNTRY (Paese) — Optional
├─ SOURCE (Come ci hai scoperto) — Dropdown
│  └─ Landing Page AZIONI
│  └─ Landing Page FONDI
│  └─ LinkedIn
│  └─ Direct referral
│  └─ Other
├─ SIGNUPDATE — Auto-filled
└─ LANGUAGE (Lingua Preferita) — IT/ES/EN/FR/DE
```

**WORKFLOW 2: Educational Email Sequence (Day 3, 7, 14, 21)**

**Email 2 — Day 3: "Come Funzionano i 5 Filtri"**
```
Subject: I 5 Filtri Che Usiamo Ogni Giorno [Video Spiegazione]

Ciao *|FNAME|*,

Tre giorni fa ti sei iscritto. Perfetto!

Oggi voglio spiegarti come funzionano i 5 filtri di Robot Trader.

🎯 I 5 FILTRI:

1️⃣ EV/FCF < 12
   Cosa significa: Quanti euro spendi per ogni euro di cash flow generato
   Perché: Cash flow = vera ricchezza, non earnings

2️⃣ P/B < 1.2
   Cosa significa: Paghi MENO del valore contabile dell'azienda
   Perché: Safety margin — margin of safety

3️⃣ ROE > 0%
   Cosa significa: Azienda genera profitti dal capitale
   Perché: Qualità dell'azienda

4️⃣ ND/EBITDA < 2.5
   Cosa significa: Debito controllato
   Perché: Rischio downside limitato

5️⃣ SCORE > 80
   Cosa significa: Ranking composito dei 4 filtri sopra
   Perché: Un'azione deve PASSARE TUTTI i filtri

📊 ESEMPIO REALE: Lennar (LEN)
- EV/FCF: 5.64 ✅
- P/B: 1.04 ✅
- ROE: 8% ✅
- ND/EBITDA: -1.40 ✅
- SCORE: 86 ✅
→ Risultato: SELECTED come opportunità di valore

🎥 Video spiegazione (5 min): https://youtube.com/robot-trader-filters

Domande? Rispondi a questa email!

A presto,
Luciano

### STEP 5: SEGMENTAZIONE

Crea questi segments in Mailchimp:

```
SEGMENT 1: "BASIC Plan"
├─ Condition: PLAN == "BASIC"
├─ Use case: Special offers for BASIC users (upsell PRO)
└─ Size: ~60%

SEGMENT 2: "PRO Plan"
├─ Condition: PLAN == "PRO"
├─ Use case: Feature updates, API documentation
└─ Size: ~30%

SEGMENT 3: "ENTERPRISE Plan"
├─ Condition: PLAN == "ENTERPRISE"
├─ Use case: Dedicated onboarding, quarterly business reviews
└─ Size: ~10%

SEGMENT 4: "Italia"
├─ Condition: COUNTRY == "IT"
├─ Use case: Italian-specific content + tax info
└─ Size: ~45%

SEGMENT 5: "Spagna"
├─ Condition: COUNTRY == "ES"
├─ Use case: Spanish-specific content + localized support
└─ Size: ~35%

SEGMENT 6: "Engaged" (Openers + Clickers)
├─ Condition: Opens last 30 days > 0 AND Clicks last 30 days > 0
├─ Use case: VIP content, beta testing features
└─ Size: ~40%
```

```

BODY:
{
  "email_address": "{{email}}",
  "status": "subscribed",
  "merge_fields": {
    "FNAME": "{{fname}}",
    "PLAN": "{{plan}}",
    "COUNTRY": "{{country}}",
    "SOURCE": "{{source}}"
