### 5. IMAGE OPTIMIZATION

**For Landing Page Images:**

1. File naming:
   ```
   WRONG: image1.png
   RIGHT: automated-stock-screener-dashboard.png
   ```

2. Alt text:
   ```html
   <img src="..." alt="Robot Trader automated stock screener interface showing 5 value filters">
   ```

3. Compression:
   - Use TinyPNG: https://tinypng.com/ (50-80% size reduction)
   - Target: <100KB per image

4. Format:
   - Use WebP format (faster loading, better SEO signal)
   - Fallback to PNG/JPG for older browsers

**Current Issues:**
