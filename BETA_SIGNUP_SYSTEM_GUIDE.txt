════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════

PROBLEMA 1: "Connection refused"
Significa che il server non sta girando.

Soluzione: Apri PowerShell e riavvia:
  cd "C:\Users\lucia\Desktop\Robot Trader 2026\PYTHON_SCRIPTS"
  python signup_handler.py

PROBLEMA 2: "Database not found"
Significa che DATABASE_RECIPIENTS.json non è nel percorso giusto.

Soluzione: Controlla che sia in:
  C:\Users\lucia\Desktop\Robot Trader 2026\PYTHON_SCRIPTS\DATABASE_RECIPIENTS.json

Se non c'è, copiane una da:
  C:\Users\lucia\Desktop\Robot Trader 2026\08_EMAIL_RECIPIENTS_SYSTEM\DATABASE_RECIPIENTS.json

PROBLEMA 3: "Email already registered"
Se un cliente si iscrive 2 volte con la stessa email.

Sistema risponde correttamente: "Email already registered"
Non è aggiunto due volte! ✅

PROBLEMA 4: Form non funziona sulla landing page
1. Verifica che il form HTML sia stato aggiunto correttamente
2. Verifica che il server sia in ascolto su http://localhost:5000
3. Check browser console per errori (F12)
